## 🚀 How to Run Locally

You can run this portfolio immediately without any complex dependencies or installations:

1. Double-click `index.html` to open it in Google Chrome, Microsoft Edge, or Firefox.
2. Or run a lightweight local server (e.g. using Python or VS Code Live Server):
   ```bash
   # From the Ahmed_Abdelhamed_Portfolio folder:
   python -m http.server 8000
   ```
   Then open `http://localhost:8000` in your browser.

## 🌐 How to Deploy for Free to GitHub Pages (Live on the Internet)

1. Create a repository on GitHub named `portfolio` or `ahmed482005.github.io`.
2. Push the files (`index.html`, `style.css`, `script.js`, `README.md`) to your repository:
   ```bash
   git init
   git add .
   git commit -m "Deploy modern AI portfolio with live interactive demos"
   git branch -M main
   git remote add origin https://github.com/ahmed482005/ahmed482005.github.io.git
   git push -u origin main
   ```
3. In GitHub: go to **Settings** > **Pages** > Select branch `main` and save.
4. Your portfolio will be live at `https://ahmed482005.github.io`!
